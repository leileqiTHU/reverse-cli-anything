# Shared runtime upgrade · 2026-10-14

Historical showcase regression, recorded before the framework was decoupled from its examples. The counts and workflows below apply to these cases only. Current generic setup and acceptance are documented in [installation](../../docs/install.md) and [acceptance](../../acceptance/README.md).

[中文](upgrades-20261014.zh-CN.md) · [Runtime](../../docs/runtime.md) · [Acceptance](../../acceptance/README.md) · [Evidence](../../evidence/upgrade-20261014.json)

The three adapters now share discovery, configuration, diagnostics, tool contracts and operation receipts. Their original entry points remain available. Native editing still belongs to each version-bound adapter; the shared layer does not invent a universal native transaction API.

## Export regression discovered and fixed

CapCut's export-finish page can start an automatic AI crop preview which hides text tracks by changing attribute bit 2. The existing content guard rejected the changed timeline. An intermediate retry produced a decodable MP4 with missing captions; independent fixture acceptance rejected that output too. Both failures remain recorded.

Inspection of shipped QML, Qt metadata and native instructions traced both frontend paths to the pinned `VECreator.dll` model function at RVA `0x3e8bfd0`. The CLI now installs a temporary guard for its own export lifecycle, bound to the expected module, function bytes, UI thread and active project. Calls outside that scope continue to the original implementation; the hook is removed during cleanup. This prevents the unwanted secondary crop without changing the saved application binary. [Static evidence](../../capcut-cli/evidence/export-postprocess-static-20261014.json) · [Implementation](../../capcut-cli/capcut_export_frontend_agent.js).

Fresh preview and final-export runs each recorded an actual suppressed crop request. Their timeline comparison passed, English and Chinese captions were visible in the final MP4, audio decoded, and edits survived reopening. The caption pixel test is specific to the generated two-second fixture, not a general OCR or semantic video test.

## Recovery findings and limits

Axure cold startup needed a longer readiness window; only read-only probes repeat. An exact late journal result resolved the earlier unknown status. A CapCut add-audio timeout was resolved only after the worker had exited and fresh state plus the native journal showed no submission. Neither mutation was blindly replayed.

An older CapCut background crop export also left the renderer busy. Native cancellation did not confirm completion. The dedicated test draft was backed up, the application restarted, failed evidence retained, and a fresh full regression passed. The original user project was reopened afterward.

Unknown outcomes remain blocked for subsequent gateway writes until inspected and resolved. The gateway cannot serialize clients that bypass it, cancel arbitrary native work, prove caller-supplied recovery evidence independently, or make unsupported application versions compatible. Full reports and artifacts remain under local `outputs/upgrade-20261014/`; the public evidence summary preserves their hashes and scope.
