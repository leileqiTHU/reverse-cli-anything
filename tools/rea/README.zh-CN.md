# 研究工具

[English](README.md) · [SOP](../../docs/SOP.zh-CN.md) · [安装框架](../../docs/install.zh-CN.md)

[REA](https://github.com/morluto/rea) 用于研究发行产物并恢复内部操作，不是安装通用框架或运行所有生成 CLI 的必需依赖。

用户指定目标后，按 REA 上游说明配置 Agent 环境。根据产物选择原生反汇编/反编译、托管反编译、打包脚本分析或运行/协议观察后端，仅安装需要的引擎，记录工具版本和目标哈希。适配器日常运行所需依赖应另行说明。

依赖分析器前，先发现当前 Agent 实际可用的工具，读取其参数说明、确认配置的后端，再检查选定产物中一小段相关内容。保留查询、工具及后端版本、覆盖范围和输出，作为就绪证据。连接器已注册或可执行程序已安装，并不证明所需分析能够运行。缺少引擎时按其当前上游说明配置，再重复该项有限检查；仍受访问或覆盖范围阻碍时保留具体原因并选择合适回退，不猜测工具名、签名或原生入口。

遵循配置的安装和缓存位置，保留已有数据，不把本机注册文件当成通用安装脚本发布。如果未使用 REA，应如实标注实际工具并保留证据，不能将所有结果统称为 REA 输出。

按[产物分流与失败回退指南](../../docs/guides/reconnaissance.zh-CN.md)缩小分析范围。工具触发大小限制或仅返回部分结果，不代表目标类型或入口不存在。保留失败查询，缩小模块、类型或函数范围，记录实际回退工具。将版本哈希、ABI 和生命周期写入[入口与版本模板](../../templates/research/README.zh-CN.md)，不在缺少证据时跨版本复用地址或虚表槽位。
