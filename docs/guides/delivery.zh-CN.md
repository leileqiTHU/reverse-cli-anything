# 交付、安装与维护
[English](delivery.md) · [工程手册](../HARNESS.zh-CN.md) · [开发工具](../development-tools.zh-CN.md)

## 三类安装分别处理

1. **框架**：Python、共享运行层和开发资源；核心安装不要求应用或反编译器。
2. **Agent Skill**：可发现入口及完整方法、辅助资源；只复制一个引用失效的 Skill 不算完整安装。
3. **目标适配器**：执行所需的原生依赖、构建配置和目标说明。

使用 [Skill 安装器](../development-tools.zh-CN.md)，将完整资源包放到目标 Agent 支持的 Skill 目录。工具要求显式位置、拒绝覆盖已有目录、记录文件哈希；根据用户配置确定安装及缓存位置，分别确认文件复制与宿主发现状态。

包内框架副本可脱离原仓库使用，注册表为空，不包含案例代码、私有二进制、凭据、本机配置、应用缓存或分析引擎。更新时先安装到新位置，审阅后按宿主正常方式替换，不覆盖未知的已有 Skill。

## 从真实工具生成说明

对已保存清单运行文档助手。它只读取数据，不导入 runtime hook，不启动应用；生成准确工具列表、输入输出契约和声明的覆盖，区分已有声明与刚执行的验证。

输出写入新目录，保留手写原生说明。生成 Skill 可作为交付起点，或被维护中的目标 Skill 引用。命令变化后重新生成，并审阅 schema 无法完整表达的单位、前置状态、异步语义和错误处理。

该助手不生成原生实现，也不猜测未知必填参数来编造成功调用。没有覆盖声明时属于未验证，而非默认支持。

## 交付清单

- 可运行适配器、明确入口和结构化结果。
- 清单、工具目录、目标依赖与配置。
- 构建映射：哈希、架构、绑定和证据。
- 请求操作的覆盖及限制，包括未验证模式。
- 状态查询、错误/结果解释与恢复指引。
- 适合目标的原生断言和产物验证器。
- 目标 Skill、命令说明和有意义的组合流程。
- 研究交接：失败候选、当前决策及未解阻碍。

Python 包在方便安装时有价值，但不强制所有目标采用。交付已安装可执行命令时，在验证范围内应从仓库外实际执行；源码目录冒烟不能证明安装包可移植。

## 审慎支持新版本

对新模块取指纹并比较构建映射，重新确认 token/RVA、签名、布局和所有权，不能只改哈希保护而保留旧地址。已支持与候选配置分别保存。

在新构建上验证一项请求操作及相关生命周期或输出，仅修改类工具需要有限写入。旧版本证据可指导研究，不能证明新版本正确。保留崩溃和未知结果，保持旧支持配置可用。

## Agent 交接

提供框架/Skill 位置、安装记录、适配器清单、支持构建、就绪查询和所需流程。继续工作时，附上适用的输入、作业或会话身份及尚未解决的操作 ID。接手 Agent 应能根据这些资源确定前提、选择命令并解释结果。

## 署名与发布

分发包包含依赖版本、许可证与必要声明；需署名的代码和资产保留来源引用。

公开发布包含有限实现和可公开证据，不包含安装器下载文件、软件私有二进制、转储、账号资料或整个研究缓存。发布及提交外部目录按用户要求的发布范围执行。
