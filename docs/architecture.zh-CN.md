# 架构

[English](architecture.md) · [SOP](SOP.zh-CN.md) · [适配器契约](adapter-contract.zh-CN.md)

`reverse-cli-anything` 将面向任意目标的框架与独立注册的适配器分开。零适配器、没有任何目标软件二进制时，也能完成安装与核心自检。

```text
用户：安装框架 → 核心配置与自检 → 等待目标任务
用户：软件 + 实际任务
  → Agent + 通用 Skill + SOP
  → 按产物选择工具，进行静态分析与运行研究
  → 适配器清单 + 原生实现 + 工具 schema + 验收
  → 公共 CLI：发现 → 校验 → 回执 → 调用 → 观察
  → 目标专属的原生状态 / 持久化 / 产物验证
```

| 组件 | 负责什么 | 不预设什么 |
| --- | --- | --- |
| Agent 方法层 | 操作范围、研究路线、实验、生命周期与交付决策 | 固定目标名单或任意二进制的自动接口恢复 |
| 文件型研究与交付助手 | 研究记录、文件指纹、引用检查、目录生成说明和完整 Skill 资源包 | 原生语义正确或宿主已发现 Skill |
| 核心配置和 doctor | 解释器、路径、注册表及可选适配器诊断 | 特定应用、桌面系统或原生依赖 |
| 清单注册机制 | 加载注册适配器及受信任的可选 Hook | 固定软件名单 |
| 工具目录与 schema | 工具发现、JSON 校验和参数翻译 | 某个软件的命令层级 |
| 调用与回执 | 进程执行、写入串行、历史回执及显式恢复 | 通用原生撤销、取消或恰好一次执行 |
| 脚手架 | 创建独立适配器骨架和待完成验收计划 | 已经恢复了原生接口 |
| 验收检查器 | 必需证据层次、结果分类及文件哈希 | 任意软件产物的语义正确性 |
| 适配器 | 版本约束、ABI、对象生命周期、完成判断、原生断言和产物检查 | 其他适配器的运行方式 |

## 扩展边界

[工程手册](HARNESS.zh-CN.md)、[工作模式](workflows.zh-CN.md)及专项[研究指南](guides/reconnaissance.zh-CN.md)指导 Agent 开发；[助手](development-tools.zh-CN.md)负责保存证据和打包说明。研究状态检查、文档生成与 Skill 安装均不运行适配器。

通过注册 `adapter.json` 接入目标，无须修改核心。默认传输向 Python 入口传入工具名和 JSON 输入；可选的适配器 Python Hook 用于兼容既有命令语法、环境诊断和结果约定。Hook 属于受信任的本机代码，仅在选择该适配器时加载，详见[契约](adapter-contract.zh-CN.md)。

核心注册表初始为空，展示元数据单独位于 `examples/registry.json`。只有 `list --examples` 才将其加入列表；为兼容旧命令，显式指定展示案例 ID 时仍可加载。正常安装和核心诊断不会加载案例。删除全部展示目录后，核心仍应可用。

## 目录

```text
reverse-cli-anything.py / .ps1     规范入口
reverse_cli/                      与具体软件无关的运行层
registry.json                     空基础注册表；可选展示索引
schemas/*.schema.json             通用清单、回执和验收契约
skills/reverse-cli-anything/       安装 / 目标研究的通用 Skill
docs/                             工程手册、专项指南、工作模式、契约与架构
templates/research/               任务、操作、入口、实验及交付记录
tests_development/                文件助手的隔离检查；不执行原生操作
tests_shared/                     合成适配器测试；不依赖展示案例
tools/                            核心配置、检查和通用适配器调用
<target>-cli/                     可选适配器实现及清单
examples/                         展示索引、兼容逻辑和历史验收脚本
```

`completed` / `ok: true` 只记录适配器完成，不代表独立原生验收。未知写入保留锁，直到观察或显式恢复；直接调用及其他状态目录不受同一公共锁约束。框架不提供通用二进制编译为 CLI 的引擎、原生事务或 MCP 服务，逆向研究由 Agent 按通用方法和契约开展。
