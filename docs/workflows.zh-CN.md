# Agent 任务模式

[English](workflows.md) · [工程手册](HARNESS.zh-CN.md)

根据对话选择流程，用户无须输入模式命令。已有授权和约束继续有效；切换流程不扩大到无关安装、发布或目标写入。

## 安装

按[安装文档](install.zh-CN.md)准备框架，将完整 Skill 资源安装到所选 Agent 支持的位置，检查复制后的资源。遵循存储偏好，报告实际路径及宿主是否需要重新加载。除非另有请求，否则不选择或研究目标软件。

## 新建操作集合

1. 按[目标任务入口](SOP.zh-CN.md#开始目标任务)开始，读取工程手册及相关技术指南，将目标拆成操作、依赖和可观察结果。
2. 查找已有适配器和公开覆盖，确认版本身份，为缺口初始化研究目录。
3. 使用已知输入和独立观察证明一项请求，记录失败候选与成功调用；仅对具有相应语义的操作选择写入、撤销和持久化检查。
4. 完成其余操作及组合流程，补齐生命周期与恢复。
5. 从实际工具目录生成说明，补充原生语义，交付明确范围的证据。

产物：适配器、目录、目标 Skill、用法、版本限制、研究决策和逐操作覆盖。脚手架属于进展，不算完成。只有现有上下文及独立研究无法消除阻碍时，才向用户索取缺失信息。

## 扩展已有适配器

读取目标 Skill、目录、版本映射和既有证据，列出请求新增项、可复用命令与兼容承诺。新增写接口往往需要先补充观察字段或生命周期能力。

保留已有命令名称和语义，除非用户要求破坏性变更。修改应聚焦，记录共享层变化。为新增行为、相关既有行为及组合流程设计检查，是否执行取决于本次用户范围。不要用生成文档覆盖已有手写内容。

产物：覆盖变化、实现、更新后的生成说明、限制及实际运行的检查。历史证据仍标为历史。

## 恢复部分完成或未知结果

任何写入前先读取回执和目标身份，确认原 worker/原生任务是否仍在运行、是否已有迟到终态结果、受影响资源或会话是否仍为预期目标。查询创建的 ID 和已完成步骤，按[恢复指南](guides/state-and-recovery.zh-CN.md)决定观察、可靠续做或明确恢复。

产物：已解决或仍未知的记录、证据、残余变化与下一步。错误文本、Python worker 已退出或超过等待期限，都不能证明回滚。不得通过换一个操作 ID 绕过未知写入锁。

## 适配另一个构建

记录候选模块指纹，与已有版本映射比较，分别确认入口位置、签名、布局和对象来源；元数据相同不证明 ABI 兼容。建立独立版本配置，验证一项请求及其适用的生命周期和输出检查。

产物：有证据的新支持配置，或经过研究但未验证的配置；保留旧版本保护。参见[交付与维护](guides/delivery.zh-CN.md)。

## 验证或审阅

执行前确定请求的层次：

| 层次 | 工作 | 不能证明 |
| --- | --- | --- |
| 文档/契约审阅 | 链接、schema、生成说明、证据引用和限制 | 当前原生执行 |
| 辅助工具验证 | 在隔离合成文件上检查框架助手 | 软件兼容性 |
| 原生操作验证 | 对固定目标执行选定工具并观察结果 | 未测命令或其他版本 |
| 工作流/可移植性验证 | 执行所需完整流程、重开、输出及新安装检查 | 任意软件普遍支持 |

记录所选验证层次与实际执行的检查。未执行项保持 `not-run`，与失败及不适用项分别报告。

## 使用已有工具

日常任务先读目标 Skill，检查就绪和当前状态，再用现有 CLI 执行并验证结果。确有缺口才转入扩展或版本适配。用户始终通过对话表达需求，内部研究及框架命令由 Agent 负责。
